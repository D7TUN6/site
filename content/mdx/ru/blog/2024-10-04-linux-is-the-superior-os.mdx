<p>LiNuX iS tHe sUpErIoR Os</p>

<p>Delete all zip files in a directory on Windows:</p>

<p>del *.zip</p>

<p>Delete all zip files in a directory on Linux:</p>

<p>find "$(pwd | awk '{ print $1 }')" -type f -name "*.zip" -exec sh -c 'for file; do if [ -w "$file" ]; then rm -f "$file"; fi; done' sh {} +</p>
