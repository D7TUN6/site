<p>🐍<b> Python хоронит GIL</b></p>

<p>Эрик С. Рэймонд, один из отцов-основателей опенсорса, еще в 2019 году предрекал скорую смерть Python из-за его главного архитектурного изъяна — Global Interpreter Lock (GIL). Этот механизм не позволял эффективно использовать многопоточность.</p>

<p>Однако годы шли, а Python только набирал популярность, упорно занимая первые строчки в рейтингах языков программирования. И вот теперь настал момент истины: начиная с октября 2025 года, Python 3.14<a href="https://www.python.org/downloads/release/python-3140/"> можно официально собрать без GIL</a>.</p>
